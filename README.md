# RKDF University Website

Official website design and modern portal for RKDF University.

🌐 **Live GitHub Pages URL:** [https://ayush-tripathii.github.io/RKDF-Dubai/](https://ayush-tripathii.github.io/RKDF-Dubai/)

## Features
- **Modern Responsive Design:** Crafted with rich typography, prestige university aesthetics, and clean layouts.
- **Accreditations & Recognitions:** Approved by UGC, AICTE, ICAR, BCI, PCI, INC, and NAAC Accredited.
- **Interactive Modals:** Admission application form, campus tour scheduler, student/faculty portal login, interactive search overlay.
- **Micro-Interactions:** 3D hover effects, scroll-triggered animations, animated stats counters, infinite corporate recruiter marquee, and interactive FAQ accordion.
